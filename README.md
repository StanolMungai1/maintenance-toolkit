# maintenance-toolkit# Maintenance Toolkit

Practical templates for plant maintenance, built from hands-on work in food-production and agricultural plants. Free to copy and adapt.

## What's inside

| File | Use it for |
|---|---|
| [preventive-maintenance-schedule.csv](preventive-maintenance-schedule.csv) | Planning and tracking preventive, condition-based and routine tasks |
| [fmea-template.csv](fmea-template.csv) | Scoring failure modes by severity, occurrence and detection (RPN) |
| [rca-template.md](rca-template.md) | Root cause analysis with 5 Whys and a fishbone check, plus a worked example |
| [loto-checklist.md](loto-checklist.md) | Lockout/tagout steps and a simple log |

## How to use

1. Download the file you need, or copy it into your own workspace.
2. Open the CSV files in Excel or Google Sheets and replace the sample rows with your own assets.
3. Add your site's own limits, intervals and procedures. Treat these as starting points, not as official standards.

> The example rows and the worked RCA are illustrative, not records of real events.

## Related practices

Preventive and condition-based maintenance, root cause analysis, FMEA, 5S, Lean, Kaizen, PDCA, and lockout/tagout safety.
